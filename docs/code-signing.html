מדיניות חתימת קודCode signing policy

עודכן ב-2 בנובמבר 2026Updated 2 November 2026

בקצרה: האפליקציה חתומה במפתח של פוקי, וכל קובץ של המוח שבמכשיר נבדק מול טביעת SHA-256 קבועה כשהוא יורד. תוכנת המחשב (Puki.exe) יצאה משימוש בגרסה 0.9.0.

In short: the app is signed with Puki's key, and every file of the device brain is checked against a fixed SHA-256 fingerprint when it downloads. The PC program (Puki.exe) was retired in 0.9.0.

מה נחתם ומה נבדקWhat is signed and checked

האפליקציה לאנדרואיד נחתמת במפתח של פוקי עצמו, ועדכון של האפליקציה מותקן רק אם הוא חתום באותו מפתח. טביעת התעודה (SHA-256): a799cab5bcf83c20c754490f8d0eb271cf844e2b7e69518760789f2a96eb3c3d

The Android app is signed with Puki's own key, and an update to the app installs only if it's signed with that same key. The certificate's SHA-256: a799cab5bcf83c20c754490f8d0eb271cf844e2b7e69518760789f2a96eb3c3d

המוח שבמכשיר (Brains, ‏Beak, הקול והאוזניים) יורד מ-Hugging Face ומ-GitHub, וכל קובץ נבדק מול הגודל וטביעת ה-SHA-256 שקבועים בתוך האפליקציה (DeviceModels.kt). קובץ שלא מתאים נמחק ולא נטען.

The device brain (Brains, Beak, the voice and the ears) downloads from Hugging Face and GitHub, and every file is checked against the size and SHA-256 fixed inside the app (DeviceModels.kt). A file that doesn't match is deleted and never loaded.

Puki.exe והמוח למחשב יצאו משימוש בגרסה 0.9.0, ולא נבנים יותר. גרסאות ישנות שלהם נשארות בדף הגרסאות ב-GitHub.

Puki.exe and the PC brain were retired in 0.9.0 and are no longer built. Their old versions remain on the GitHub releases page.

פרטיותPrivacy policy

התוכנה הזו לא מעבירה שום מידע למערכות אחרות ברשת, אלא אם המשתמש או מי שמתקין או מפעיל אותה ביקש זאת במפורש.

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.

בפועל: האפליקציה בודקת ב-GitHub אם יש גרסה חדשה (רק בגרסה מ-GitHub), ומורידה את המוח מ-Hugging Face ומ-GitHub רק כשההורים לוחצים על ההורדה. שום מידע על הילדים לא יוצא מהמכשיר. מדיניות הפרטיות

In practice: the app checks GitHub for a new version (in the GitHub build only), and downloads the brain from Hugging Face and GitHub only when the parents tap the download. Nothing about the child leaves the device. Privacy policy
